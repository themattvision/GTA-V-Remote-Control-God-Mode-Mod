Inizia da qui

Configura GodMode Mod Remote Control in questo ordine. Funziona soltanto con GTA V Legacy in modalità Storia sulla tua rete Wi-Fi locale.

1. Installa l'app Mac. Nella finestra della DMG trascina GodMode Mod Remote Control su Applicazioni. Poi aprila dalla cartella Applicazioni. Rimane nella barra dei menu in alto a destra.
2. Consenti i permessi sul Mac. Quando macOS lo chiede, consenti Rete locale e Accessibilità. Se Accessibilità non compare, apri Impostazioni di Sistema, Privacy e sicurezza, Accessibilità, abilita GodMode Mod Remote Control e riaprila.
3. Installa l'app iPhone. Apri sull'iPhone questo link TestFlight: https://testflight.apple.com/join/TfJtcUy3
4. Collega i dispositivi alla stessa Wi-Fi. Non usare una rete ospiti e disattiva le VPN durante il pairing.
5. Abbina in sicurezza. Apri GTA Remote sull'iPhone, seleziona il computer e approva soltanto se sui due dispositivi compare lo stesso numero.
Stato TestFlight: il link pubblico è attivo. Al 3 settembre 2026 l'installazione esterna è ancora in attesa della Beta App Review di Apple. I tester interni possono già usare il build 0.3.0 (4).

Start here

Set up GodMode Mod Remote Control in this exact order. It works only with GTA V Legacy Story Mode on your own local Wi-Fi.

1. Install the Mac app. In the DMG window, drag GodMode Mod Remote Control onto Applications. Then open it from Applications. It stays in the menu bar at the top-right of your screen.
2. Allow the Mac permissions. When macOS asks, allow Local Network and Accessibility. If Accessibility does not appear, open System Settings, Privacy & Security, Accessibility, enable GodMode Mod Remote Control, and reopen it.
3. Install the iPhone app. Open this TestFlight link on your iPhone: https://testflight.apple.com/join/TfJtcUy3
4. Put both devices on the same Wi-Fi. Do not use a guest network. Turn off VPNs while pairing.
5. Pair safely. Open GTA Remote on the iPhone, select the computer, and approve only when the same number appears on both devices.
TestFlight status: the public link is enabled. External installation is still waiting for Apple Beta App Review as of 3 September 2026. Internal testers can use build 0.3.0 (4) now.
