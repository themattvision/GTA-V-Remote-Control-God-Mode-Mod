Set up GodMode Mod Remote Control in this exact order. This is for GTA V Legacy Story Mode on your own local Wi-Fi only.

1. Install the Mac app. In the DMG window, drag GodMode Mod Remote Control onto Applications. Then open GodMode Mod Remote Control from Applications. It stays in the menu bar at the top-right of your screen.
2. Allow the Mac permissions. When macOS asks, allow Local Network and Accessibility. If Accessibility does not appear, open System Settings, Privacy & Security, Accessibility, then enable GodMode Mod Remote Control and reopen it.
3. Install the iPhone app. On your iPhone, open this TestFlight link: https://testflight.apple.com/join/TfJtcUy3
4. Put both devices on the same Wi-Fi. Do not use a guest network. Turn off VPNs while pairing.
5. Pair safely. Open the remote on the iPhone, select your computer, and approve only if the same number is shown on both devices.
TestFlight status: the public link is enabled. External installation is waiting for Apple Beta App Review as of 3 September 2026. Internal testers can use build 0.3.0 (4) now.
